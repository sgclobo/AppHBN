### 📂 Song Library Organization

The songs are now organized in **`app/_components/`**. This structure allows for faster bundling and better organization as your project grows.

| File | Sub-Data and Category |
| :--- | :--- |
| **`songs_data.ts`** | **The Central Hub.** It imports all other files and exports the final `SONGS_DATA` array used by the app. |
| `songs_misa_tetum.ts` | All Tetum-language "Misa" songs (Entrada, Gloria, Responsorial, etc.). |

### 🛠️ How to Add New Songs

To add a new song, you should **NOT** edit the main `knananuk.tsx` or `songs_data.ts`. Instead, follow these steps:

#### 1. Choose the Correct Module
Depending on the category or language of the song, open the corresponding file in `app/_components/`.

#### 2. Add the Song Object
Add a new object at the bottom of the array in that file. **Important:** Follow the exact structure below:

```typescript
{
  id: 101,                  // A unique number
  category: "Misa",         // Must match existing categories for grouping
  section: "Comunhão",      // Used for Misa sub-headers/accordions
  title: "VAI E ENSINA",    // The main title seen in the list
  refrain: "Go and teach...", // (Optional) Refrain text
  verses: [                 // Array of stanzas
    "Verse 1 text goes here.",
    "Verse 2 text goes here."
  ],
}
```

#### 3. Best Practices for the Song Data
*   **JSON Syntax:** Ensure all property names (like `id`, `category`, `title`) are exactly as shown.
*   **Strings:** Use double quotes or backticks for long text. If your text contains single quotes (e.g., *Ha'u*), it's safest to use backticks (\` text \`).
*   **Category Names:** Be extremely careful with spelling. If you write "Missa" (with two 's') instead of "Misa", the app will create a brand new category header.
*   **ID Numbers:** Ensure the `id` is a unique number. The app automatically sorts the lists by these IDs.

#### 4. To add to "Misa Latin", "Ingles", or "Indonesia"
Since these categories are now "Flat Lists," the `section` property is still required for the data structure, but it won't be displayed in the UI. You can put something generic like `"Default"` or repeat the category name for those.

> [!TIP]
> After adding a song to a sub-module (like `songs_other.ts`), it is automatically included in the app because `songs_data.ts` is already set up to import it. You just need to save the file and refresh Expo!
